# **Política de Privacidade – Anota aí**

Última atualização: 10 de dezembro de 2025

A sua privacidade é importante para nós. Esta Política de Privacidade descreve como o aplicativo Anota aí coleta, utiliza, armazena e protege as informações dos usuários.

Ao utilizar o aplicativo, você concorda com os termos descritos abaixo.

**1. Informações Coletadas**

O aplicativo Anota aí coleta apenas informações necessárias para seu funcionamento.

1.1. Informações fornecidas pelo usuário

Listas de compras criadas.

Itens adicionados às listas.

Esses dados são inseridos manualmente pelo próprio usuário.

**1.2. Informações técnicas (Firebase)**

O app pode coletar automaticamente dados como:

Identificador anônimo do dispositivo.

Informações de desempenho.

Registros de erros (Crashlytics).

Esses dados não identificam você pessoalmente.

**2. Uso das Informações**

Os dados coletados são usados exclusivamente para:

Armazenar e sincronizar suas listas.

Garantir o funcionamento correto do app.

Melhorar desempenho, estabilidade e experiência de uso.

Não vendemos, alugamos ou compartilhamos seus dados com terceiros para fins comerciais.

**3. Armazenamento e Segurança**

Os dados são armazenados no Firebase, que utiliza:

Criptografia (HTTPS) na transmissão.

Servidores e infraestrutura do Google.

Regras de segurança para limitar acessos indevidos.

Embora adotemos medidas de proteção, nenhum sistema é totalmente imune a falhas.

**4. Compartilhamento com Terceiros**

O aplicativo não compartilha dados pessoais com terceiros, exceto:

Serviços essenciais ao funcionamento do app (como Firebase).

Quando exigido por lei.

**5. Direitos do Usuário**

O usuário pode:

Excluir dados diretamente no aplicativo.

Remover o aplicativo a qualquer momento.

Solicitar informações ou exclusão total dos dados que estão no Firebase.

Para solicitações, use o e-mail de suporte abaixo.

**6. Uso por Crianças**

O aplicativo não é destinado especificamente a crianças, mas não coleta dados pessoais sensíveis.
Caso um responsável identifique uso indevido, poderá solicitar a exclusão dos dados.

**7. Alterações na Política**

Esta Política pode ser atualizada ocasionalmente.
A data no topo será sempre ajustada para refletir a versão mais recente.
